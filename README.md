# EconSim — симулятор стран мира

3D-глобус с 197 странами, на котором идёт ежемесячная симуляция экономики, политики и войн.
Внутри работают агенты: **правительства** (ведут себя как государства) и **граждане** (ведут себя как люди).
Можно запускать сценарии («что если…») и сравнивать мир с «базовым» миром без вмешательств.

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
npm run data       # (опц.) обновить данные из World Bank API
npm run sim 240    # прогон модели без UI (проверка калибровки)
node scripts/scenario-test.mjs   # эффект каждого сценария vs база
```

## Данные (public/data)
- `countries.json` — 194 независимые страны + Тайвань, Палестина и Косово (`python3 scripts/fetch_data.py --add UNK` добавляет одну страну без перекачки остальных); World Bank (WDI + WGI) + `world-countries`; пропуски → медиана региона (поле `imputed`).
- `world-50m.json` — границы Natural Earth. `sources.json` — каталог источников (используемых и кандидатов: IMF, UN Comtrade, SIPRI, UCDP, V-Dem, OWID …).

## Модель (src/sim)
| Файл | Что делает |
|---|---|
| `world.js` | расстояния, торговые веса (гравитационная модель), базовые отношения |
| `engine.js` | шаг в 1 месяц: рост, инфляция, безработица, долг, стабильность, нефть, войны, дрейф отношений |
| `decisions.js` | агент-правительство: правило Тейлора, стимулы/austerity, пошлины и ответные меры, санкции, армия, помощь, объявление войн |
| `citizens.js` | агенты-граждане: работа, настроения, протесты, эмиграция, выборы и перевороты |
| `scenarios.js` | 14 готовых сценариев; эффекты: shock / oil / tariff / sanction / war / relation |
| `blocs.js` | НАТО, ЕС, БРИКС, ШОС, ОПЕК+, ОДКБ…, союзы, ядерные державы, соперничества |

Базовый и основной миры используют счётчиковый ГСЧ (`rng.js`) — одинаковые шоки, поэтому «Δ к базе» = чистый эффект сценария.

## Ограничения
Учебная модель, не прогноз. Коэффициенты подобраны по здравому смыслу; торговые потоки — гравитационная модель, а не UN Comtrade;
мир стартует в состоянии мира (текущие конфликты не загружены — запускаются сценариями).
Идеи дальше: калибровка по IMF WEO / UN Comtrade / UCDP, валюты и курсы, отраслевая структура, климат, ресурсы.

## Калибровка

`npm run history` скачивает ряды World Bank 2000–2024 (рост, инфляция, безработица) в `data/history.json`.
`npm run calibrate [сидов]` сравнивает медианные по странам моменты модели и реальности (σ и AR(1) роста и инфляции, корреляция с мировым ростом, наклон Окуна, разрез по доходу). Параметры шума — объект `P` в `src/sim/engine.js`; для перебора: `P='{"gNoise":9}' npm run calibrate`.
`npm run backtest` прогоняет сценарии пандемии, финкризиса и нефтяного шока и сравнивает с реальными эпизодами.

Известные расхождения: наклон Окуна (модель −0.15 против −0.09 по медиане стран; эмпирика занижена из-за ошибок измерения), `infl median HIC` на ~30% выше, дефляция почти не встречается.

## События текстом («Промт»)

Вкладка «Промт» принимает фразу вроде «Россия нападает на Украину, нефть +30% на год» или «Мощное землетрясение в Японии», разбирает её в эффекты сценария (`src/sim/nlp.js`, правила и словари, без внешних моделей), показывает разбор, позволяет поправить длительность и задержку или открыть результат в конструкторе. Блок «Влияние на мир» сравнивает мир с базовым без вмешательств. Несколько событий можно писать через запятую или «и».

## Оценка на многих прогонах (ансамбль)

После калибровки случайные события большие, и один прогон показывает в основном шум. Кнопка «📊 Оценить» (у пресетов, в конструкторе и во вкладке «Промт») прогоняет сценарий против базового мира на 10–40 сидах в Web Worker и показывает медиану и коридор 10–90%: ВВП мира (в конце и в худшей точке), пики инфляции и безработицы, войны, объявленные агентами сверх базы, и страны, которые теряют или выигрывают в большинстве прогонов. Расчёт идёт от стартового мира 2026 г., а не от текущего состояния основного прогона.

Из командной строки: `npm run ensemble -- pandemic 20 60` или `npm run ensemble -- "Китай вторгается на Тайвань" 20 60` (ядро — `src/sim/ensemble.js`).

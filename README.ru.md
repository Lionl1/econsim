# EconSim — симулятор стран мира

[English](README.md) · **Русский**

3D-глобус с 197 странами, на котором идёт ежемесячная симуляция экономики, торговли, валют, фондовых рынков, крипты, политики и войн.
Внутри работают агенты: **правительства** (ведут себя как государства), **граждане** (ведут себя как люди) и **корпорации** (переносят производство из-под барьеров).
Можно запускать сценарии («что если…») и сравнивать мир с «базовым» миром без вмешательств.

## Интерфейс
Слева — разделы (Сценарии, Промт, Конструктор, Рынки, Данные; повторный клик сворачивает панель), сверху — ключевые показатели мира с мини-графиками и отклонением от базы, справа — инспектор мира или страны (Обзор, Экономика, Рынки, Политика, Действия), снизу — время, шкала событий и лента новостей, у глобуса — выбор метрики и легенда.

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
npm test           # быстрые тесты: движок, сценарии, разбор фраз, календарь, ансамбль
npm run calendar -- 2000 8   # календарь: модель против фактического мирового роста с 2000 г.
npm run data       # (опц.) обновить страны из World Bank API
npm run trade      # (опц.) двусторонняя торговля UN Comtrade, ~2 ч (публичный API отвечает ~20 с на запрос); --build — пересобрать из скачанного
npm run markets    # (опц.) валюты, курсы, прогнозы IMF, крипта, фондовые рынки, корпорации
npm run sim 240    # прогон модели без UI (проверка калибровки)
node scripts/scenario-test.mjs   # эффект каждого сценария vs база
```

## Данные (public/data)
- `countries.json` — 194 независимые страны + Тайвань, Палестина и Косово (`python3 scripts/fetch_data.py --add UNK` добавляет одну страну без перекачки остальных); World Bank (WDI + WGI) + `world-countries`; пропуски → медиана региона (поле `imputed`).
- `trade.json` — экспорт каждой страны по партнёрам, UN Comtrade (товары, HS TOTAL, 2023/2022). Поток берётся из отчёта импортёра (CIF→FOB), иначе зеркально из отчёта экспортёра; так покрыты и неотчитывающиеся страны (Тайвань = «Other Asia, nes»). Пары, по которым нет ни одного отчёта, получают гравитационную оценку. В текущем снимке 122 страны с отчётами об импорте и 121 об экспорте: публичный API начал отказывать до того, как скачались США, Великобритания, Вьетнам и ещё несколько стран; `npm run trade` продолжит с места остановки.
- `markets.json` — валюты и режимы курса (world-countries + классификация IMF AREAER, упрощённо), текущие курсы (open.er-api.com), волатильность курсов (World Bank PA.NUS.FCRF 2008–2024), прогноз IMF WEO 2026–2031 (рост, инфляция, безработица), BTC/ETH (CoinGecko), капитализация и волатильность фондовых рынков (World Bank CM.MKT.LCAP, CM.MKT.INDX.ZG), 63 крупнейшие корпорации (курируемый список + капитализация Wikidata P2226, если свежая и правдоподобная).
- `world-50m.json` — границы Natural Earth. `sources.json` — каталог источников (используемых и кандидатов).

## Модель (src/sim)
| Файл | Что делает |
|---|---|
| `world.js` | расстояния, реальная матрица торговли (Comtrade, гравитация как запасной вариант), доли экспорта/импорта, валюты, прогнозы, базовые отношения |
| `params.js` | все параметры: откалиброванные и литературные (со ссылками), диапазоны для розыгрыша в ансамбле |
| `trade.js` | спрос Армингтона: пошлины/санкции/войны перестраивают доли поставщиков, переток к третьим странам, пошлины → разовый скачок цен |
| `fx.js` | курсы: плавающие (ставки, риск, нефть, шум), привязки со срывом, еврозона, долларизация; перенос в цены, эффект на экспорт |
| `equity.js` | фондовые индексы стран, отрасли, эффект богатства; корпорации-агенты и переносы производства; «чиповый шок» при войне вокруг Тайваня |
| `crypto.js` | цена BTC (тяжёлые хвосты, связь с рисковыми активами), доля крипты у населения (прокси), запреты |
| `ensemble.js` | ансамбль прогонов с тремя слоями неопределённости (см. ниже) |
| `engine.js` | шаг в 1 месяц: рост, инфляция, безработица, долг, стабильность, нефть, войны, дрейф отношений |
| `decisions.js` | агент-правительство: правило Тейлора, стимулы/austerity, пошлины и ответные меры, санкции, армия, помощь, объявление войн |
| `citizens.js` | агенты-граждане: работа, настроения, протесты, эмиграция, выборы и перевороты |
| `scenarios.js` | 19 готовых сценариев; эффекты: shock (в т.ч. fx / equity / cryptoBan) / oil / tariff / sanction / war / relation / peace / crypto / sector / company / relocate |
| `blocs.js` | НАТО, ЕС, БРИКС, ШОС, ОПЕК+, ОДКБ…, союзы, ядерные державы, соперничества |

Базовый и основной миры используют счётчиковый ГСЧ (`rng.js`) — одинаковые шоки, поэтому «Δ к базе» = чистый эффект сценария.

## Торговля, валюты, рынки — на чём основано
- **Торговля** — CES-спрос Армингтона, как в структурных гравитационных моделях (Anderson & van Wincoop 2003; Head & Mayer 2014): доля поставщика ∝ исходная доля × (1+барьер)^(−σ), σ≈3 (2–5 в ансамбле), подстройка ~18 мес. (короткая эластичность ниже длинной — Boehm, Levchenko & Pandalai-Nayar 2023). Санкции ≈ пошлина 60% → −77% двусторонней торговли (Global Sanctions Database, Felbermayr et al. 2020). Пошлины почти полностью переносятся в цены импорта (Amiti, Redding & Weinstein 2019). Переток к третьим странам — как Вьетнам/Мексика после пошлин 2018–19 (Fajgelbaum et al. 2024). Издержки для импортёра ~0.25% ВВП на п.п. средней пошлины × долю импорта (порядок оценок Yale Budget Lab 2025).
- **Валюты** — реальный курс тянется к равновесию (разница реальных ставок с США, риск-премия: стабильность/санкции/война/дефолт, нефть для экспортёров), шум по истории курса; перенос в цены 0.1 (богатые) / 0.3 (EM) (Burstein & Gopinath 2014); реальная девальвация 10% → ~+1% ВВП через чистый экспорт (IMF WEO 2015, гл. 3), у EM частично съедается долларовыми долгами (Kearns & Patel, BIS 2016). Привязки срываются при перекосе >35% или сценарном давлении.
- **Фондовые рынки** — индекс растёт с номинальным ВВП + премия, падает с ростом реальной ставки, общий мировой фактор (σ≈15%, как MSCI World) + свой шок (волатильность по S&P/World Bank за вычетом курса); эффект богатства 2 цента на доллар неожиданного изменения.
- **Корпорации** — стоимость = индексы рынков, где компания зарабатывает + отрасль + потери от барьеров на рынках и в цепочке поставок (страна производства); при сильных барьерах переносят производство в дружественные хабы (Индия, Вьетнам, Мексика, …), хаб получает приток инвестиций.
- **Крипта** — BTC с t-распределёнными шоками (σ≈60%/год), связан с рисковыми активами и ставкой ФРС; доля владельцев — прокси (интернет × инфляция × доход), открытых данных по странам нет.

## Ограничения
Учебная модель, не прогноз. Торговля — только товары (услуги масштабированы по итогу World Bank); валютные режимы упрощены; корпорации — 63 крупнейшие, без отраслевой межстрановой структуры; доля крипты — прокси.
Мир стартует в состоянии мира (текущие конфликты не загружены — запускаются сценариями).

## Калибровка

`npm run history` скачивает ряды World Bank 2000–2024 (рост, инфляция, безработица) в `data/history.json`.
`npm run calibrate [сидов]` сравнивает медианные по странам моменты модели и реальности (σ и AR(1) роста и инфляции, корреляция с мировым ростом, наклон Окуна, разрез по доходу). Параметры — объект `P` в `src/sim/params.js`; для перебора: `P='{"gNoise":9}' npm run calibrate`.
`npm run backtest` прогоняет сценарии пандемии, финкризиса и нефтяного шока и сравнивает с реальными эпизодами.

Известные расхождения: наклон Окуна (модель −0.15 против −0.09 по медиане стран; эмпирика занижена из-за ошибок измерения), `infl median HIC` на ~30% выше, дефляция почти не встречается.

## События текстом («Промт»)

Вкладка «Промт» принимает фразу вроде «Россия нападает на Украину, нефть +30% на год» или «Мощное землетрясение в Японии», разбирает её в эффекты сценария (`src/sim/nlp.js`, правила и словари, без внешних моделей), показывает разбор, позволяет поправить длительность и задержку или открыть результат в конструкторе. Блок «Влияние на мир» сравнивает мир с базовым без вмешательств. Несколько событий можно писать через запятую или «и». Понимает также валюты («рубль упал на 30%», «доллар укрепился»), крипту («крах биткоина», «Китай запретил крипту»), рынки и отрасли («обвал фондовых рынков», «пузырь ИИ лопнул»), компании («акции Nvidia −40%», «Apple переносит производство в Индию») и мир («все страны объединились»).

## Календарь глобальных событий: что было бы без них

Вкладка «🗓 Календарь»: 18 событий 2000–2025 гг. (крах доткомов, 11 сентября, финкризис 2008, долговой кризис еврозоны, Арабская весна, Фукусима, Крым и санкции, обвал нефти 2014, Brexit, торговая война США и Китая, COVID-19, война в Украине, подъём ставок ФРС, кризис в Красном море, пошлины США 2025 и др.). Выбираете год старта — мир запускается с фактическим состоянием на конец предыдущего года (World Bank: ВВП, население, рост, инфляция, безработица, долг, курсы). До 2026 г. потенциальный рост — тренд перед стартом минус β-конвергенция (~2 п.п. на лог-единицу роста дохода), с 2026 г. — прогноз IMF.

Пользоваться просто: выбрать год (быстрые кнопки 2000, 2008, 2014, 2019, 2022), кликнуть по событиям, которых «не было», нажать большую кнопку «Показать мир без …» внизу панели. Кнопка переносит мир, проигрывает глобус до 2031 г. и открывает окно результата (насколько мировой ВВП в 2031 г. был бы больше, рост по годам с коридором, кому события стоили больше всего); сверху плашка переключает глобус «Как было / Без событий». Шкала времени в этом режиме показывает весь период 2000–2031 с иконками событий — клик по году или событию тоже переносит туда.

Считаются два мира с одной случайностью: «как было» (все события) и «без отмеченных». Таблица по годам: фактический рост мира, обе модели, эффект и оценка «без событий» = факт − эффект модели; «📊 Оценить на 20 вариантах» даёт медианы и коридор 10…90%. Насколько «как было» похоже на историю: со старта в 2000 г. корреляция с фактическим мировым ростом 0.84, средняя ошибка 0.85 п.п. (`npm run calendar`): 2009 г. −0.8% (факт −1.3%), 2020 г. −3.1% (факт −2.9%), 2021 г. +7.8% (факт +6.5%). Набор событий и сила их эффектов — допущения модели.

## Неопределённость и прогноз

Как это делают на практике и что взято в модель:
1. **Случайные события** (алеаторная неопределённость) — разные сиды: шоки роста, инфляции, курсов, рынков, решения агентов.
2. **Параметры модели** (эпистемическая) — в байесовских DSGE ЦБ модель гоняют по выборкам параметров из апостериорного распределения. Здесь апостериора нет, поэтому ключевые параметры разыгрываются равномерно в диапазонах оценок из литературы (`PRANGES` в `params.js`: эластичность торговли, санкционный барьер, перенос пошлин и курса, фискальный мультипликатор, Оукен, эффект богатства…).
3. **Величина события** — логнормальный множитель с медианой 1 и σ=0.35 (шок «−6%» ≈ от −3.4% до −10.6% в 80% вариантов).
4. **Прогноз как опора** — фан-чарты IMF и Банка Англии строятся вокруг консенсус-прогноза с шириной по историческим ошибкам. Базовый мир привязан к IMF WEO 2026–2031 (потенциальный рост, якорь инфляции, естественная безработица); в окне оценки коридор базового роста модели показан рядом с прогнозом IMF, пересчитанным в рыночные веса. Ширина коридора (~±1.5 п.п.) сопоставима с историческими ошибками годовых прогнозов IMF.

## Оценка на многих прогонах (ансамбль)

После калибровки случайные события большие, и один прогон показывает в основном шум. Кнопка «📊 Оценить» (у пресетов, в конструкторе, во вкладке «Промт» и в действиях страны) прогоняет сценарий против базового мира на 10–40 сидах в Web Worker и показывает медиану и коридор 10–90%: ВВП мира (в конце и в худшей точке), пики инфляции и безработицы, войны, объявленные агентами сверх базы, и страны, которые теряют или выигрывают в большинстве прогонов. Расчёт идёт от стартового мира 2026 г., а не от текущего состояния основного прогона.

Из командной строки: `npm run ensemble -- pandemic 20 60` или `npm run ensemble -- "Китай вторгается на Тайвань" 20 60` (ядро — `src/sim/ensemble.js`); `NOPARAMS=1` отключает слои 2–3.
